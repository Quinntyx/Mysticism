## Exact wire/cache API

Package `io.github.mysticism.net`; vectors/bases are defensively copied, profile/dimension checked on packet decode. Sessions use connection nonce + monotonic generation/epoch **only for transport**, never geometry. Client keeps an epoch high-water mark across world/player replacement and acknowledges accepted scene bootstrap; server does not publish glyph/terrain deltas before ack.

`SpiritScenePayload(session, sequence, deep, sourceObserved, binding, peers, ghosts, meshes, drops)`:

- `Binding(String dimension,String landmarkId,Vec3d sourcePosition,Vec384f captured)`; **landmarkId="" is valid UNOWNED**, not a fabricated landmark. `captured` is this snapshot's current semantic q, not a frozen origin. Shallow binding uses terrain's actual current source position.
- `Peer(UUID id,Vec384f q,Basis384f basis,boolean deep,Binding binding,float yaw,float pitch,Ghost appearance)`. `appearance` supplies real pose/equipment/player profile even when vanilla XYZ tracking never created the peer client entity. Its position is incidental appearance snapshot metadata; render peers from their q through CURRENT observer q/basis/head, never that position.
- `Ghost(UUID id,int entityId,String type,String landmarkId,Vec3d sourcePosition,String pose,float yaw,float pitch,float bodyYaw,float headYaw,float width,float height,GameProfile profile,List<DataTracker.SerializedEntry<?>> tracked,List<Equipment> equipment)`.
- `Equipment(EquipmentSlot slot,ItemStack stack)`. Player profiles retain actual UUID/name and signed texture property. `tracked` contains copied actual changed-from-default vanilla data tracker values (variants/colors/age/pose etc), not invented type defaults. Renderer special-cases source PLAYER with `OtherClientPlayerEntity`/profile, applies tracked values, pose/head/body rotations and equipment; safely skip registry create failures/mod incompatibility and show unavailable status, **not a fabricated marker**. Call EntityRenderDispatcher directly as parent native-scene mixin requires.
- `Drop(UUID id,int entityId,Vec384f q,Vec384f target,Vec3d proxy,ItemStack stack)`. `target==null`, `semantic()==false` explicitly means an unindexed/over-budget real vanilla recovery proxy; not a made-up embedding target. Renderer still projects snapshot q through current observer. Real authoritative stack remains on vanilla entity; wire is a bounded visual copy, not inventory replacement.
- Scene `meshes` remains empty retired coarse metadata. **Use dedicated terrain stream.**

Glyph `SpiritDeltaPayload.Added(id,bits,clusterId,clusterSlot,slot)` transmits no world position. Use `added.glyph()` / client glyph list with existing `SpiritGlyphSelection.position(glyph,currentQ,currentBasis,interpolatedHead,radius)`. Membership is radius-wide density-aware clustering, not nearest K/random centers. Slot changes are transported even when item identity persists. Visibility caches exact member bits and gates cached native arrays against one current-q snapshot on tick (no repeated per-member vector clones/hash-collision shortcuts).

Terrain `SpiritTerrainPayload(session,sequence,part,parts,full,removed,frame)`:

- `frame` is owner's canonical `TerrainMeshFrame`; each Cell transports **key, material, landmarkId, sourceMin, min, affine axisX/axisY/axisZ, LOCAL collision boxes, opacity**. Renderer and MeshCollision receive identical columns/local boxes. Palette allows **64 properties**, matching owner.
- `batches(session,sequence,current,previous)` sends only changed cells/removals; metadata-only revisions send no unchanged cells. Palette/source-dimension changes force full. Client assembles/deletes by stable cell key, then publishes ONE complete frame; never fragments into live collision. Bounds 8 parts, 256 cells/part, 2048 cells, 256 materials, <=256KiB/part. Latest frames coalesce; unchanged revisions are not resent. At most 4 observers updated/tick, minimum 5 ticks between updates/viewer. Actual deformation of every cell still requires their updated affine data; this is not a compressed vertex-delta codec.

## Implemented server behavior / bounds

- Semantic peer discovery includes only navigation's REAL `semanticReady/modelCompatible` players and reads actual server players independently of vanilla XYZ tracking (scan <=128, output <=16). Actor authentication comes only from C2S connection player with current handler/player identity. Deep touch requires both deep, mutually advertised peers, same realm/server, semantic eligibility, **both** projected head-center distances <=4, mean axis alignment >=.95 and **both current mesh rays** clear; then calls navigation touch. Shallow no-op, no damage/attunement. Rate limit 10 ticks.
- Up to 64 active transport/visibility observers; inactive connection nonce/epoch retained until disconnect. Scene has bounded 16 source ghosts, 32 drops; individual appearance <=8KiB, tracked entries <=96, equipment <=8. Packet budget 950000 bytes; actual scene encoding preflight rejects over-budget snapshots with visible transport status.
- Shallow source ghost lookup lazily aborts after 64 nearby candidates, sorted UUID; no materializing a huge entity list. Up to **8 source observers** have one radius-4 vanilla ticket each (5x5 entity-ticking / 9x9 FULL area, plus vanilla dependency statuses). Before adding, prove the ENTIRE ChunkLevels dependency pyramid already generated to its required status, via non-loading current holder status or async native storage NBT. Never call generation/getChunk(create=true), never infer from a region's completeness alone. Bounds <=2048 proof positions/observer, 64 metadata peeks/poll, 8 pending IO/observer. Absent/retrogen/unknown statuses fail closed and retry. Release on region/dimension/player/exit/deep/disconnect/stop. Already-loaded FULL source centers stay observable during retention proof (preserves initial source entities); `sourceObserved=false` exposes currently unavailable source data to renderer.
- No placeholder q is used for a semantic drop: tracking waits for navigation's actual `semanticReady/modelCompatible`; pending/unowned entry uses the explicit non-semantic vanilla recovery path. Vanilla dropped ItemEntity stays authoritative: stack, vanilla pickup delay/ownership, merge, normal-world behavior and ordinary mod inventory recovery remain. Up to128 semantic drops steer q towards actual current-profile registry-item embedding, persist stamped q/target/lifetime; incompatible saved vectors are discarded while original stack/gravity survive. Observer-range expiry only after a complete <=128-player check; larger populations defer range expiry, never falsely delete. Independent 6000-tick cap remains. Per-server native observer arrays are captured once/tick; item selection/pickup checks are staggered. No model inference/IO on entity/server tick.
- One closest-observer physical proxy follows semantic motion with point-swept current-mesh obstruction; external vanilla/mod velocity and displacement contribute bounded motion. Proxy Y remains inside world bounds to prevent carrier void loss. Vanilla close pickup is gated by projected reach; periodic collision invocation supports another within-reach viewer despite proxy XYZ. Unindexed/over-budget items are explicitly streamed as visible non-semantic vanilla proxies, not silently removed to fake visuals.
